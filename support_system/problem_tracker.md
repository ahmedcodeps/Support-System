# Problem Tracker

## Problem 1
**Problem:** Duplicate request IDs could be entered.

**Solution:** Use a set to check whether the ID already exists.

**Data structure:** Set

---

## Problem 2
**Problem:** Requests need to be processed in the order they arrive.

**Solution:** Use a queue.

**Data structure:** Queue

---

## Problem 3
**Problem:** Users need to undo their most recent update.

**Solution:** Save previous updates in a stack.

**Data structure:** Stack

---

## Problem 4
**Problem:** Customers need to find requests.

**Solution:** Search by request ID or customer name.

**Approaches:** Dictionary lookup and linear search.

---

## Problem 5
**Problem:** Requests need to be organized by date, priority, or status.

**Solution:** Use sorting.

**Approaches:** Python Timsort and selection sort.
